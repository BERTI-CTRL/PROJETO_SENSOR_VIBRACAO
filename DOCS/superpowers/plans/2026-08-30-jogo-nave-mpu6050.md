# Jogo de nave MPU6050 — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar um jogo Pygame independente em `game/`, no qual a inclinação do MPU6050 move uma nave para desviar de meteoros.

**Architecture:** Uma thread serial guarda somente a amostra mais recente do protocolo atual do Arduino. O loop Pygame roda a 60 FPS, passa o `ay` ao controlador de inclinação e atualiza entidades, colisões, placar e telas. As regras de controle e geometria permanecem puras para testes automatizados.

**Tech Stack:** Python 3.11+, Pygame, pyserial, unittest.

**Spec:** `DOCS/superpowers/specs/2026-08-30-jogo-nave-mpu6050-design.md`

## Global Constraints

- Criar o jogo somente em `game/`; não modificar `sensor/`, `realtime/` nem o firmware Arduino.
- Usar o protocolo serial de oito campos: `contador,tempo_arduino_us,ax,ay,az,gx,gy,gz`.
- Controle padrão: `ay - ay_neutro`; `C` mede o neutro por 1,5 s e `I` inverte a direção.
- O jogo deve permanecer jogável pelas setas esquerda/direita se não houver serial.
- O loop visual deve rodar a 60 FPS; a serial deve estar em thread própria.
- Não usar imagens, sons ou outros assets externos.

```python
# game/controller.py
from collections.abc import Iterable


class TiltController:
    def __init__(self, dead_zone_g: float, full_tilt_g: float, smoothing: float) -> None:
        self.dead_zone_g = dead_zone_g
        self.full_tilt_g = full_tilt_g
        self.smoothing = smoothing
        self.neutral_ay = 0.0
        self.inverted = False
        self._filtered = 0.0

    def calibrate(self, samples: Iterable[float]) -> float:
        values = list(samples)
        if not values:
            raise ValueError("A calibração precisa de ao menos uma amostra.")
        self.neutral_ay = sum(values) / len(values)
        self._filtered = 0.0
        return self.neutral_ay

    def update(self, ay: float | None) -> float:
        if ay is None:
            return 0.0
        raw = (ay - self.neutral_ay) / self.full_tilt_g
        if abs(ay - self.neutral_ay) <= self.dead_zone_g:
            raw = 0.0
        raw = max(-1.0, min(1.0, raw))
        if self.inverted:
            raw = -raw
        self._filtered += self.smoothing * (raw - self._filtered)
        return self._filtered

    def toggle_inversion(self) -> bool:
        self.inverted = not self.inverted
        self._filtered = 0.0
        return self.inverted
```

```python
@dataclass(frozen=True)
class SensorSample:
    counter: int
    ax: float
    ay: float
    az: float


def parse_sensor_line(line: str) -> SensorSample | None:
    fields = line.strip().split(",")
    if len(fields) != 8:
        return None
    try:
        return SensorSample(
            counter=int(float(fields[0])),
            ax=float(fields[2]),
            ay=float(fields[3]),
            az=float(fields[4]),
        )
    except ValueError:
        return None
```

Implement `SensorReader` com `threading.Lock`, `threading.Event` e `threading.Thread(daemon=True)`. Abra `serial.Serial(port, baudrate, timeout=0.25)`, leia `readline()`, decodifique com `errors="replace"`, use `parse_sensor_line()` e substitua a última amostra sob lock. Ao capturar `serial.SerialException` ou `OSError`, grave a mensagem em `status`, defina `is_connected = False` e encerre a thread. `stop()` deve sinalizar o evento e fechar a porta aberta, se existir.

```python
def circle_hits_rect(circle_x: float, circle_y: float, radius: float, rect: tuple[float, float, float, float]) -> bool:
    x, y, width, height = rect
    nearest_x = max(x, min(circle_x, x + width))
    nearest_y = max(y, min(circle_y, y + height))
    return (circle_x - nearest_x) ** 2 + (circle_y - nearest_y) ** 2 <= radius ** 2
```

On `C` in the calibration state, start a 1.5-second collection of `reader.latest_sample().ay`; once completed call `controller.calibrate(calibration_samples)` and change to `playing`. On `I`, call `controller.toggle_inversion()`. On `R`, reset score, meteors and ship and return to `calibration`. On `Escape` or the window-close event, exit cleanly and call `reader.stop()` in `finally`.

During `playing`, combine `controller.update(sample.ay if sample else None)` with keyboard direction from arrows, clamp to `[-1, 1]`, and call `ship.move(direction, dt, WINDOW_WIDTH)`. Spawn `Meteor` objects at random horizontal positions above the screen; use a spawn timer that lowers from 0.80 s toward 0.26 s as score increases. Increase meteor downward speed from 210 px/s gradually. A collision sets `state = "game_over"`; passing meteor yields a small score bonus.

Draw procedurally with `pygame.draw`: a navy gradient-like star field, bright triangular ship, exhaust particles, meteor circles with crater dots, a top HUD with score/record and a lower status strip. Use `pygame.font.Font(None, size)` so no font file is required. Draw the calibration status, current serial status and keyboard fallback instructions explicitly.
